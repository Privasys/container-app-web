container-app-web

One app, three surfaces. This page is the static surface: measured code served in the clear. Each button below calls a different surface and shows the raw answer.

Read public status public

GET /api/v1/public/status is declared public in the manifest. It is served in the clear, carries no identity, and the runtime marks it X-Privasys-Transport: public. 


  


  

    
Who am I private

    

      GET /api/v1/me is not declared, so it is private: only a
      sealed session or an RA-TLS connection reaches it. A signed-in page
      calls it through the
      Privasys auth SDK,
      which seals the request inside the browser and gives the app the
      user's per-app subject. This template does not include the SDK. The
      button makes a plain fetch instead, to show what a browser gets
      without a sealed session: 403 sealed-transport-required,
      answered by the runtime before the app sees anything. (Run locally,
      with no runtime in front, the app answers 200 with an empty subject.)
    

    
    

  


  

    
Stored webhook events private

    

      GET /api/v1/events lists the events accepted on the
      public webhook POST /api/v1/webhooks/demo. Receiving is
      public (the sender signs the body); reading is private. Same plain
      fetch, same refusal.
